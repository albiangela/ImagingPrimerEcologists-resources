# BehavioralVideoAnalysis

This repository is a **tutorial / read-more companion** for the Behavioral Video Analysis paper.

It is designed to:
- collect important links related to the paper,
- provide practical examples in Jupyter notebooks,
- stay easy to browse and easy to extend through pull requests.

## Repository layout

- `links/` — curated links (paper, code, datasets, related resources)
- `notebooks/` — example notebooks showing how workflows are done

## Start here

1. Read `links/README.md` for a curated link collection.
2. Open notebooks in `notebooks/` to follow worked examples.

## Contributing

Contributions are welcome through pull requests, including:
- adding useful links,
- adding or improving tutorial notebooks,
- improving explanations for new users.

Please keep additions concise, clearly labeled, and beginner-friendly.
