# Photogrammetry

## Code and software

Overview of popular open-source and proprietary tools for photogrammetry and 3D reconstruction.

| Software | Description | Reference/Source |
|----------|-------------|------------------|
| [Meshroom](https://github.com/alicevision/Meshroom) | Open-source, node-based 3D reconstruction pipeline. | AliceVision / Meshroom |
| [COLMAP](https://colmap.github.io/) | Open-source photogrammetry software for 3D reconstruction. | Schönberger et al. 2016 |
| [OpenDroneMap](https://github.com/OpenDroneMap/ODM) | Open-source software for processing aerial drone imagery. | OpenDroneMap |
| [Metashape](https://www.agisoft.com/) | Commercial photogrammetry software for 3D reconstruction. | Agisoft Metashape |
| [Pix4D](https://www.pix4d.com/) | Commercial drone software with photogrammetry integration. | Pix4D |
| [DJI Terra](https://enterprise.dji.com/dji-terra) | Commercial DJI mapping and 3D reconstruction software. | DJI Terra |

## Notes for contributors

Keep additions concise, clearly labeled, and beginner-friendly.
