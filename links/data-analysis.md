# Data Analysis

## Code and software

| Software | Description | Reference |
|----------|-------------|-----------|
| [movement](https://movement.neuroinformatics.dev/community/index.html) | Python library for cleaning, visualizing, and analysing pose-estimation and tracking data | Sirmpilatze et al. 2025 |
| [animovement](https://github.com/roaldarbol/animovement) | R ecosystem for reading, checking, processing, analysing, and visualizing animal movement data | Roald-Arbøl 2025 |
| [swaRmverse](https://marinapapa.github.io/swaRmverse/) | R library for analysis and visualization of collective motion data | Papadopoulou 2025 |
| [move](https://cran.r-project.org/package=move) | R package for storing, managing, visualizing, and analysing animal tracking data | Joo et al. 2020 |
| [amt](https://cran.r-project.org/package=amt) | R package for managing tracking data and conducting habitat-selection and step-selection analyses | Signer et al. 2019 |
| [moveHMM](https://cran.r-project.org/package=moveHMM) | R package for behavioural-state inference from movement data using hidden Markov models | Michelot et al. 2016 |
| [momentuHMM](https://cran.r-project.org/package=momentuHMM) | R package for generalized hidden Markov models of animal movement, including multiple data streams and covariates | McClintock and Michelot 2018 |
