# Important links

Use this page to collect and maintain key references for the Behavioral Video Analysis paper.

## Suggested sections

- **Paper**: canonical publication and preprint links
- **Code**: implementation repositories and tooling
- **Data**: datasets used in the paper or related benchmarks
- **Background reading**: related methods, tutorials, and surveys

## Add a link

When adding links via pull request, include:
- a short title,
- the URL,
- one sentence describing why it is useful.

Example:
- `Project website` — `https://example.org` — Overview and quick-start resources.
