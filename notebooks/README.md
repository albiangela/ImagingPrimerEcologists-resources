# Notebook examples

This folder contains Jupyter notebook examples (`.ipynb`) that show how tasks are performed step-by-step.

## Notebook guidelines

- Name notebooks clearly (for example: `01_data_loading.ipynb`, `02_inference.ipynb`).
- Keep each notebook focused on a single learning objective.
- Include short markdown explanations between code cells.
- Prefer reproducible examples with explicit dependencies and data assumptions.

## Add a notebook

Submit notebooks through pull requests and include:
- what the notebook demonstrates,
- required inputs/dependencies,
- expected output.
